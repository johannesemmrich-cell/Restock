Ein zweiter Einstieg unter „Käufe wiederherstellen“. Wer einen Code bekommt, sucht ihn meist beim Kauf.

Alternative B: nur die Paywall bekommt den Einstieg, die Einstellungen verlieren die Promo-Zeile ganz. Weniger Fläche, aber Tester ohne sichtbare Paywall finden ihn nur über „Restock Pro freischalten“.

Wirkung: Das Eingabefeld, die Fehlermeldung und die Erfolgsmeldung der Einstellungen entfallen. Erfolg zeigt iOS selbst, danach schaltet die App Pro frei, ohne dass der Tester etwas tippt.
