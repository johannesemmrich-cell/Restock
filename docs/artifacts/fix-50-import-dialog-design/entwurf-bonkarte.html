Die Bon-Prüfkarte hat ein Namensproblem

Vier Beobachtungen aus der Bon-Prüfliste — und zwei Wege, sie zu beheben. Ein Weg macht den Bontext selbst wählbar, der andere lässt ihn Beschriftung bleiben.

Belegt

Eine Karte ohne Markierung ist kein Schönheitsfehler

Links dein Screenshot. Rechts derselbe Zustand, heute Morgen im Simulator nachgestellt — über den echten Weg aus der Teilen-Erweiterung, ohne eine Zeile Code zu ändern.

Warum das zählt: Gespeichert wird der Name, den die Karte nicht anzeigt — hier „Butter“. Restock merkt sich dauerhaft „BTR → Butter“, ohne dass du das je bestätigt hast. Und wenn die Auflösung danebenliegt, lernt sie den Fehler mit.

Zuschnitt

Zu viel für eine Lieferung — Vorschlag: drei

Alles zusammen liegt bei rund 300 Zeilen Änderung und damit über unserer Grenze. In dieser Reihenfolge kommt das Wichtigste zuerst, und jede Lieferung steht für sich.

Zuerst

Die Auswahl stimmt wieder

Immer genau eine markierte Zeile, und der aufgelöste Name steht sichtbar darin. Behebt den einzigen Punkt, der heute falsche Daten schreibt.

Danach

Der Bontext wird lesbar

Größer, in voller Textfarbe, mit „Kopieren“ beim langen Druck. Rein sichtbar, ohne Auswirkung auf gespeicherte Namen.

Zum Schluss

Der Bontext wird wählbar

Eigene Auswahlzeile in lesbarer Schreibweise. Der größte Eingriff — er ändert eine Zusage, die seit dem Umbau der Karte gilt.

Offen

Drei Fragen an dich

01

Entwurf A oder Alternative B? Empfehlung: A — er erfüllt alle vier Punkte, du hast die wählbare Bon-Zeile ausdrücklich gewollt.

02

Dreigeteilt in der gezeigten Reihenfolge — oder alles in einem Rutsch? Empfehlung: dreigeteilt, damit der Datenfehler nicht auf den Rest wartet.

03

Schreibweise der Bon-Zeile: „SKYR NATUR 500G“ wird zu Skyr natur 500g (heutige Regel), zu Skyr Natur 500g (jedes Wort groß) oder bleibt unverändert?
